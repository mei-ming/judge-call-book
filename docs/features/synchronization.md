# 資料同步

資料同步功能可以將外部系統資料與目前專案內容保持即時一致。

## 同步狀態切換 (Animated WebP 範例)

當按下同步按鈕時，系統狀態會在「就緒」、「同步中」與「完成」之間自動切換：
