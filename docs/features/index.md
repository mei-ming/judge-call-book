# 功能介紹

在現代 Web APP 環境中，各項功能模組緊密配合以提供順暢的審查與調度流程。

## 核心功能清單

- **[資料同步](/features/synchronization)**：跨系統同步審查紀錄與即時通訊狀態。
- **[範例功能](/features/example-feature)**：展示進階功能模組與相關配置。

## 媒體使用規範

所有功能頁面皆遵循以下媒體呈現規範：
- **Animated WebP**：展示短時間（3~8 秒）無聲的 UI 微互動。
- **MP4 影片**：展示具備開始與結束的完整流程教學。
