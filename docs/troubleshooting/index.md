# 疑難排解

本頁面列出使用系統時常見的問題及其排除步驟。

## 常見問題 (FAQ)

### Q1: 點擊同步按鈕後無回應？

**排解步驟：**
1. 檢查網路連線是否正常。
2. 確認後端 API 伺服器狀態。
3. 重新整理頁面後再次嘗試。

### Q2: 登入時提示權限不足？

**排解步驟：**
1. 聯絡系統管理員核對帳號角色。
2. 確認是否有重複登入或 Token 過期情況。

### Q3: 影片或動畫無法正常播放？

**排解步驟：**
1. 請確認瀏覽器支援 WebP 與 H.264 MP4 格式。
2. 檢查網路防火牆是否阻擋媒體串流。
