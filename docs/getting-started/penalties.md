# 新增判罰

## 從桌列表新增判罰

列表模式下點擊「詳情」，網格模式下長按桌次，會進入桌次詳情，可看到該對桌的玩家。點擊玩家 id 後即可新增判罰。

注意由於可能手動更改配對，需確認玩家 id 是否正確。

## 從玩家列表新增判罰

在玩家列表可搜尋 id，點擊玩家後新增判罰。

<iframe src="https://scribehow.com/embed/__V-2ieroPSD24e6z2jMh48g" width="800" height="679" allow="fullscreen" style="aspect-ratio: 1 / 1; border: 0; min-height: 480px"></iframe>

### 玩家列表內無該玩家 id

部分情況玩家可能不在配對表內，如第一輪手動加入配對的玩家。這時在玩家列表的搜尋輸入完整 id 會自動產生一個暫時資料，點擊後即可新增判罰。

# 判罰核准

當有判罰被新增時，擁有組長權限裁判會在右上選單顯示未審核判罰數量，進入判罰記錄審核判罰。

並非組長核准後才算正式判罰，此功能只提供給組長快速檢視判罰狀況。若遇到拒絕的情況，來得及處理就由組長過去說明，若無法就做為賽後檢討。
