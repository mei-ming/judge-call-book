# 什麼是 EOR

End of Round

每輪結束為確保比賽進度

時間到後確認未完成桌次

並且注意玩家的遊戲節奏


## EOR 簡易流程

1. 剩餘約 10 分鐘時過去找到 EOR，EOR 會分派桌次範圍，記錄未完成桌次並回報。

2. 剩餘約 5 分鐘時過去找 EOR。EOR 會指派桌次過去盯桌，都結束後找 EOR 回報並且等待下批盯桌桌次。

3. 一直重複 2，直到所有桌次都結束。

> EOR 需要保留人力處理 Judge Call
