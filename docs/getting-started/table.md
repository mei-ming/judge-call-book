# 桌次狀態

預設桌次狀態都為結束

在 [EOR 簡易流程](./index.md#eor-簡易流程) 第一步記錄未完成桌次中，點擊桌次將狀態改為進行中。資料會同步更新。

第二步盯桌結束後將對應的桌次再點一次改為結束。

有列表及網格模式可以選擇。
