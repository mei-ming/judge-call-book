# 登入教學

本頁面說明如何登入系統，並示範 Scribe 操作教學嵌入方式。

## 登入步驟說明

1. 開啟瀏覽器並前往系統入口頁面。
2. 輸入您的電子信箱與密碼。
3. 點擊「登入」按鈕以進入主儀表板。
